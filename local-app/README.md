# Local App

Mac-only quality-of-life launcher files live here. They are intentionally
non-critical and stay separate from the app's main runtime code.

Usage:

```bash
./local-app/install-local-app
./local-app/open-local-app
```

`install-local-app` compiles `~/Applications/Phrase2Photon.app`, which launches
the local runtime on demand and opens it in your browser.
